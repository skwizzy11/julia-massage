# Джулия — студия массажа

Статический лендинг. Для локального просмотра откройте `index.html` в браузере. Файлы `style.css`, `script.js`, `studio.png` и `details.png` должны находиться рядом.

Публикация: GitHub Actions разворачивает сайт в GitHub Pages при изменениях ветки `main`. В настройках репозитория Pages необходимо выбрать источник **GitHub Actions**.

Изображения сгенерированы для концепции. Перед публичным использованием уточните телефон, адрес, услуги, стоимость и часы работы у студии.
